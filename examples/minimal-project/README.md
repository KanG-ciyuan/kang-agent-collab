# Minimal project setup

This example uses `project_id: my-project` and a suggested `.agent-collab/` directory inside the adopting project.

1. Copy `PROJECT_IDENTITY.example.yaml` to the project's chosen identity location.
2. Replace repository and authority placeholders with real, authorized locations.
3. Copy `MANIFEST.example.yaml` for the current task.
4. Replace the baseline SHA and confirm every permission before work starts.

Do not add secrets or private local paths to either file.
