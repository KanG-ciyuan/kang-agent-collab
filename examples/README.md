# Examples

These examples are intentionally generic, anonymous, and free of machine-specific paths. Copy only the records your project needs and replace every placeholder.

| Example | Purpose |
|---|---|
| [`minimal-project/`](minimal-project/) | A small Project Identity plus Full Manifest for an engineering task |
| [`handoff-example/`](handoff-example/) | A clean-state engineering Handoff and matching Takeover Check |
| [`capability-profile-example/`](capability-profile-example/) | A cautious profile for a hypothetical runtime configuration |

The `.example.yaml` files are examples, not additional canonical contracts. If an example conflicts with [references/contracts.md](../references/contracts.md), the canonical contract wins.
